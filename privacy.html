KITT Backup Privacy Policy

This policy covers only the KITT Backup integration, one OAuth client in the owner's Google Cloud project.

Data accessed: This integration requests the Google Drive API scope drive.file. Google describes this scope as allowing an app to create new Drive files, or modify existing files that the user opens with or shares with the app.

How data is used: This integration uses that access to create and upload encrypted backup archives to a dedicated backup folder in the owner's Google Drive. It does not read, modify, or delete other Drive files.

Data storage: Backup archives are stored in the owner's Google Drive account and on the owner's personal server. Archives are encrypted with AES-256-GCM. The encryption key is not included in the archives uploaded to Google Drive.

Data sharing: Google user data is not sold or shared for advertising or unrelated purposes. Backup archives may be accessed or downloaded by the owner and by services acting on the owner's instructions to operate or verify the backups. The server hosting provider stores the server copy, and the owner's authorized personal-assistant service has downloaded archives to verify that restores work.

Users: This integration is operated by its owner for personal use and is not offered to other users.
